selectHelp 第一版核心使用流程

目标：先给结果，再让用户纠偏；从打开到决定控制在 1～2 分钟。

👋
打开小程序

静默登录
获取时间、位置、天气

→
✨
自动生成 3 个候选

自做与外卖动态混合
说明入选理由和关键信息

→
🤔
用户判断

选中一个
或补充预算、时间、口味等条件

分支 A：选择“自己做”
🥘
  1. 查看匹配原因、耗时和现有食材覆盖率
  2. 查看食材用量与完整烹饪步骤
  3. 缺少食材自动加入采购清单
  4. 确认本餐选择，记录用餐历史
分支 B：选择“点外卖”
🛵
  1. 查看商家、菜品、评分和营业状态
  2. 展示可获得的价格、配送费与送达时间
  3. 缺少实时数据时明确提示，不显示猜测值
  4. 确认本餐选择，记录用餐历史与预计花费
餐后反馈闭环

喜欢 / 一般 / 不喜欢 → 调整后续推荐权重 → 更新历史与消费统计

异常与降级

定位被拒绝时让用户手动选择深圳区域；天气或商家接口失败时继续使用其余条件推荐；可用候选不足 3 个时明确说明并允许放宽条件。
