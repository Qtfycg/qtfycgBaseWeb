selectHelp 第一版页面结构

采用 3 个底部入口：决定吃什么、家中食材、我的。核心决策始终放在第一屏。

✨ 吃什么
3 个推荐候选
自做与外卖动态混合
调整条件
预算、时间、口味、距离
候选详情
菜谱 / 采购清单 / 商家菜品
🥬 食材
家中食材
名称、数量、单位、保质期
临期提醒
按过期风险排序和筛选
采购清单
由已选菜谱生成，可手动勾选
👤 我的
历史与统计
选择记录、外卖次数、预计花费
偏好设置
预算、口味、距离、清除学习结果
菜谱投稿
提交文字菜谱、查看审核状态
管理员审核
仅管理员身份可见
导航原则
  • 打开后直接进入“吃什么”，不出现启动问卷。
  • 筛选条件使用底部弹层，不让用户离开推荐结果。
  • 自己做与外卖共用候选卡片外框，详情页按类型显示不同内容。
  • 管理员入口按身份隐藏，普通用户不会看到管理功能。
