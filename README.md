# qtfycgBaseWeb

集中存放个人开发过程中编写过的前端项目代码，包括小程序、管理后台、H5 页面、跨端项目以及前端练习项目。

## 仓库定位

主要用途：

* 统一归档前端项目代码
* 记录前端项目开发过程
* 沉淀前端工程实践
* 配合后端项目和项目文档进行统一管理
* 展示个人前端相关项目经验

## 分支规则

本仓库采用以下分支模型：

```text
main：稳定归档分支
dev：日常开发分支
```

规则说明：

* `main` 分支用于保存相对稳定的项目代码
* `dev` 分支用于日常开发、修改和整理
* 日常开发优先提交到 `dev`
* 稳定后通过 Pull Request 合并到 `main`
* 禁止直接向 `main` 分支提交代码

## 开发流程

```text
dev 开发
→ 提交代码
→ 创建 Pull Request
→ 合并到 main
```

## 提交规范

提交信息建议使用以下格式：

```text
feat: 新增功能
fix: 修复问题
docs: 修改文档
style: 代码格式调整
refactor: 代码重构
test: 测试相关
chore: 配置、依赖或工程调整
```

示例：

```text
feat: 新增用户登录页面
fix: 修复页面跳转异常
docs: 补充项目说明
chore: 初始化前端项目结构
```

## 维护说明

本仓库会随着个人项目开发过程持续更新。每个项目应尽量保持独立目录、独立说明、独立依赖配置，避免不同项目之间相互污染。
